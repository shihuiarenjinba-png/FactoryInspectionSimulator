# FactoryInspectionSimulator — 2026-10-18 の初期バランス監査

## 課題の発見と修正
初期実装は全数検査・校正が利益面でもほぼ一方的に有利になり、納期や人件費を考える意味が薄かった。

このため、以下を相互に調整した。
- 発見し損ねた不良の保証・顧客対応費用を、極端な全数検査偏重にならない水準へ
- 検査費、校正費、人件費、遅延費を増額し、リスク・コスト・納期の3つが影響するように
- 仕事の契約単価が顧客信用に連動し、品質を長期的に軽視すると不利になるように
- 高価な検査方針が選べなくなったときは、安価な検査への切替を可能にする
- 最低限の固定費すら払えない場合は、操作不能ではなく経営終了として状態を確定する

数式と係数はゲーム用の架空値であり、現実の製造業の検査確率・安全基準ではない。

## 数値検査と解釈
GitHubのエンジンに基づき、120の乱数シードで同じ初日の製造ロットについて7つの固定方針の利益を比較。

| 初日の利益が最大となった方針 | 120ロット中 |
| --- | ---: |
| 無検査・1人 | 54 |
| 抜き取り25%・2人 | 12 |
| 標準50%・2人 | 16 |
| 重点75%・3人 | 13 |
| 全数100%・4人 | 12 |
| 全数＋校正100%・3人 | 13 |
| 全数100%・1人の残業 | 0 |

**一日だけを見れば無検査が高い利益を出す場合も多い。** しかし見逃した不良品は信用低下と補償費を生み、長期の契約単価に影響するため、毎日それが正しいとは限らない。短期利益と長期信頼の衝突をプレイヤーに示す。

45シード×最大90日の固定方針を検証した結果、100%検査・1人だけに頼る方針は大幅な納期遅れで早期破綻しやすく、100%検査・4人の方針は利益と品質を両立しやすい。ただしこれは選んだ6種類の定型戦略に限る観測で、ゲーム全体の最適方針を証明するものではない。
