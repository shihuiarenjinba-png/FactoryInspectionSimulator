# FactoryInspectionSimulator — 検査ラインの一日

**開発版 v0.1 / Windows買い切り販売はHOLD。** このfeatureブランチが開発中ソースの正本です。mainは空リポジトリ初期化用READMEだけを保存しています。

「品質を守るか、納期を急ぐか」。工場の品質管理責任者となり、検査の範囲、作業人員、修理、残業、設備校正を選び、納期・顧客信用・利益を維持するオフライン経営ゲームです。

## 基本操作
1. 今日の注文（製品・数量・価格・納期・おおまかなリスク）を確認
2. 検査率0/25/50/75/100%、検査員1〜4人を設定。修理・残業・校正は詳細設定
3. 検査・出荷の結果を確認し、次の注文へ

製造ロットの不良品は乱数シードと営業日により確定し、**検査方針を変更しても不良品の製造数は変わらない**。検査では検出漏れがあり、見逃しには返品対応費用と信用低下、作業に時間をかけすぎると納期遅れ費用が発生する。検査費用、賃金、修理費、出荷収入は一致するよう台帳計算する。

端末のローカルストレージで自動保存し、JSONで書き出し・読み込みができます。壊れたセーブは自動上書きせず、元データを退避できる方式を採用しています。

## ソース検証
Node.js 20以上で `npm test`。依存パッケージはありません。`index.html` を対応ブラウザで開くとローカル試作ゲームとして起動する設計です。GitHub Actionsは `.github/workflows/source-tests.yml`。

本アプリは架空の娯楽用モデルであり、現実の製品や工場の品質・安全性を証明するものではありません。
